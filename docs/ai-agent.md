# 航仔：内置 AI Agent

航仔是 AstroMan 内置的接口调试 Agent。它由你自备的模型 API Key 驱动，既能聊天、答疑、出方案，也能调用 61 个业务工具直接操作软件。

> 设计原则：模型只负责理解与决策，所有真实网络请求、文件读写、数据库修改、压测执行都由本地 Rust 工具完成；写操作必须经过确认。

## 支持的模型服务

| 协议 | 适用服务 |
|---|---|
| OpenAI 兼容 | DeepSeek、Kimi、智谱、通义千问、硅基流动、OpenRouter、Ollama、自建网关 |
| Anthropic | Claude |
| Google Gemini | Gemini |

在「航仔 → 模型服务」里填写 Base URL、模型与 API Key。模型可一键从服务商拉取真实清单（缓存 24 小时），也可手填；服务商列表只回显 Key 掩码，留空保存即沿用原 Key。

## 两种模式

| 意图 | 行为 |
|---|---|
| 闲聊、知识问答、解释代码、写文案、出方案 | 直接回答，不调用工具 |
| 明确指向本机项目 / 接口 / 报告，或说「帮我查 / 改 / 跑」 | 进入操作模式，先只读工具取真实数据，再按写操作确认流程执行 |

纯聊天输出工具块属于错误行为；方案类问题不会为了凑数据去翻你的项目。

## 能做什么

- 建项目、集合、接口，批量修改与删除
- 真实发送 HTTP 请求并解读响应
- 编写前置 / 后置脚本、断言、签名与加解密
- 批量运行、生成并保存压测计划、启动 / 停止压测
- 查看历史、报告、运行记录、Cookie、环境变量
- 调用 12 个离线工具（JSON、编码、哈希、正则、JWT、差异、UUID 等）
- 长尾工具通过 `tool_search` 按中英文关键词检索后调用

## 安全与确认

- 所有新建 / 修改 / 删除 / 导入导出 / 发起压测先给完整计划，用户确认后弹结构化确认卡（任务 / 影响对象 / 参数 / 风险 / 预检）
- 取消不执行且不重试；确认与拒绝都会写入工具流水
- 工具结果、附件、页面快照统一包「不可信数据」标签，防止提示词注入
- 工具结果与导出内容统一脱敏（Bearer、token、password、cookie 等）
- API Key 使用 AES-256-GCM 加密后存本机 SQLite，绝不上传

## 上下文与费用

- 按模型上下文窗口动态分配预算，顶部预算条显示轮次、本轮 token、估算费用、上下文占用与窗口大小
- 历史过长自动异步压缩成摘要，最近几轮原文保留；可手动压缩或暂停
- 单轮最多 8 次工具调用；同工具同参数自动复用结果，避免原地打转
- 每次模型调用记录 token、耗时、估算费用与本轮提问，入口「用量统计」，保留 1 年

## 会话与复盘

- 会话支持标题 / 正文搜索、置顶、导出 Markdown
- 消息支持复制、引用、重新生成、编辑重发、删除
- 工具调用按轮次记录 `round` / `trace_id` / 超时标记，可在「复盘时间线」查看并导出脱敏诊断包

## 常见问题

- **Key 安全吗？** 加密存本机，列表只回显掩码，不经过 AstroMan 服务器。
- **必须联网吗？** 调用云端模型需要联网；也可接 Ollama 等本地模型完全离线运行。
- **会自己删数据吗？** 不会。删除类工具必须经你确认，取消即不执行。
- **怎么停止？** 生成过程中点「停止」，在途工具结果会被丢弃，不再自动继续。

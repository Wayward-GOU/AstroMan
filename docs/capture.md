# 抓包

> 侧边栏「抓包」（`/capture`）。本机 MITM 代理，录制 HTTP/HTTPS、按域名分组查看、导出 HAR / ZIP、改参重发，以及断点改包、本地映射与弱网模拟。流量**只存内存**，重启即清空；拦截规则保存在本机，重启后仍在。

## 30 秒上手

| 步骤 | 操作 | 说明 |
|---|---|---|
| 1 | 点「录制」 | 默认监听 `127.0.0.1:8888`，端口被占用会自动向后找 |
| 2 | 点「CA 未安装」→「一键安装」 | HTTPS 解密前提；Windows 装进当前用户受信任根，无需管理员 |
| 3 | 点「接管系统代理」 | 只影响 Windows 当前用户；也可手动把代理指向 `127.0.0.1:8888` |
| 4 | 打开浏览器 / App 发请求 | 左侧按域名分组出现流量，点击看详情 |

命令行验证：

```bash
curl -x http://127.0.0.1:8888 http://example.com
curl -x http://127.0.0.1:8888 https://example.com
```

## 证书与 HTTPS

- 证书在 `<数据目录>/certs/`，设置抽屉可看 SHA-1 / SHA-256 指纹与有效期。
- 「重新生成根证书」会让旧证书立即失效，已安装的旧证书必须点「重新安装」覆盖。
- Firefox 使用独立证书库和代理设置，需要单独导入证书、单独填代理。
- 安装后状态会自动刷新，已信任后不再轮询；仍显示未信任时点「刷新」，多半装的是旧证书，重新安装即可。
- macOS / Linux 当前不支持一键安装系统代理和证书，需要手动导入 PEM、手动设置代理。
- 部分 App 做了证书固定（pinning），这类流量无法解密；HTTP/3（QUIC）不经过代理，必要时关闭浏览器 QUIC。

## 手机抓包

1. 设置抽屉把「监听地址」切到 `0.0.0.0（手机）`，点「开始录制」。
2. 手机与电脑连**同一 Wi-Fi**，手机 Wi-Fi 代理填 `电脑局域网IP:端口`（设置里会直接显示可复制地址，不要填 127.0.0.1）。
3. 设置抽屉「导出」根证书，传到手机安装。
   - iOS：安装描述文件后，还要到「设置 → 通用 → 关于本机 → 证书信任设置」打开完全信任。
   - Android：装到「用户」证书；Android 7+ 的 App 默认不信任用户证书。
4. 手机浏览器先访问一个 HTTP 页面确认代理生效，再打开目标 App。

**手机开了代理像断网**：几乎都是根证书没装或没信任。MITM 会拒绝所有无法解密的 HTTPS；先装证书，或临时关掉手机代理恢复上网。

## 微信小程序

| 情况 | 做法 |
|---|---|
| 自己的小程序 | 微信开发者工具 → 设置 → 代理 → 手动代理 `127.0.0.1:8888`；详情 → 本地设置勾选「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」 |
| 别人的小程序（优先） | 用 iPhone，系统级信任根证书后成功率更高 |
| 别人的小程序（Android） | 微信可能绕过 Wi-Fi 代理、也不认用户证书；通常需要 root 把证书装进系统证书目录 |
| 以上都不行 | AstroMan 不做 VPN / TUN 全局劫持，无法强制接管所有 App 流量 |

## 查看与导出

- 左侧按域名分组，支持关键字过滤（域名 / 路径 / 方法 / 状态）、只看错误、展开 / 折叠、自动滚动。
- 详情页签：概览、请求（头 + body）、响应（头 + body）、原始报文；文本可格式化、复制、另存，图片直接预览。
- 顶部「导出 HAR」导出全部；域名分组**右键 → 导出该分组 HAR** 只导出该域名。
- 顶部「导出 ZIP」或分组右键「导出该分组 ZIP」：解压后直接看，不需要再打开 AstroMan：

  ```text
  astroman-capture-20261103-1430/
    index.html          双击打开，汇总 + 每条流量的请求 / 响应链接
    README.txt          目录说明
    summary.json        条数、域名、请求 / 响应体量
    capture.har         标准 HAR，可导入 DevTools / Charles
    flows/0001-POST-host/
      meta.json         方法、URL、状态、耗时、头、body 元信息
      request.txt       请求行 + 请求头 + 文本 Body
      response.txt      状态行 + 响应头 + 文本 Body
      response.body.png 图片 / 二进制原始内容（有内容时）
  ```

- 容量上限：5000 条 / 128 MB body；单条 body 最多保留 2 MB 前缀，超过 8 MB 不缓冲，图片只预览 1 MB 内。出现「丢弃」时先导出再清空。

## 改参重发

详情页点「重发」，可改方法、URL、请求头与请求体。

- **录制中**：请求经本机代理发出，会新增一条流量并自动选中。
- **未录制**：直连目标，响应只显示在「重发结果」弹窗，不写入列表。
- 自动剔除 `host` / `content-length` / `connection` 等由客户端重算的头；不跟随重定向，超时 120 秒。
- 原请求体是二进制且未修改时按原样发送；二进制 body 不允许在弹窗里编辑。

## 断点、本地映射与弱网

顶部「拦截」打开规则抽屉，三个页签共用一份本机配置（`<数据目录>/capture/intercept.json`）。开关切换立即生效；规则改完点「保存当前页」。

| 能力 | 命中后发生什么 | 关键限制 |
|---|---|---|
| 断点 | 请求发出前 / 响应下发前暂停，弹窗里改包 | 120 秒未处理自动放行；最多同时挂起 32 条；二进制、流式（SSE / 下载）或超大 body 只能改头与状态码 |
| 本地映射 | 不访问服务器，直接返回内联内容或本地文件 | 文件每次命中实时读取，最大 50 MB；可改状态码、Content-Type 与响应头 |
| 弱网 | 请求首包加延迟与抖动、按带宽限速、按丢包率直接返回 504 | 带宽按响应体大小折算等待，单次最多 120 秒；作用范围留空 = 全部流量 |

规则匹配：

- URL 含 `*` 走通配，不含 `*` 按「包含」判断；只写 `host/path` 也能命中。
- 方法留空 / ANY 表示不限；断点阶段可选请求（入参）、响应（返参）或两者。
- 本地映射命中后直接返回，不再走响应断点，也不访问上游。

断点操作：

1. 「拦截」→「断点」→ 添加规则，例如 `*/api/order/*`，启用后保存。
2. 触发请求，弹窗出现后改方法 / URL / 请求头 / 请求体，或响应状态码 / 响应头 / 响应体。
3. 「放行」原样继续；「改包放行」应用修改；「中止」直接断掉该请求（返回 403）。
4. 列表里本地映射的流量带「本地」标记，断点改过的带「已改」标记。

本地映射：匹配 URL 后选「内联内容」直接写 JSON / HTML，或选「本地文件」指向磁盘文件；改完文件保存即生效，不用重启录制。

弱网：先选预设（4G / 3G / 弱 Wi-Fi / 极差）再微调，或直接填延迟、抖动、带宽、丢包率。丢包会直接返回 504，用来验证 App 的重试与降级逻辑。

## 排错对照

| 现象 | 原因 | 处理 |
|---|---|---|
| 只看到 CONNECT，没有 HTTPS 明文 | 根证书未信任 | 安装 / 重新安装根证书后重启目标程序 |
| 装完仍提示未信任 | 重新生成过证书 | 覆盖安装当前证书 |
| 手机填 `127.0.0.1:8888` 抓不到 | 127.0.0.1 指向手机自己 | 监听切 `0.0.0.0`，填电脑局域网 IP |
| 浏览器能抓，命令行走代理抓不到 | 程序没走系统代理 | 显式 `curl -x http://127.0.0.1:8888` 或手动配置 |
| 停止后电脑上不了网 | 系统代理未恢复 | 点「恢复系统代理」，或重启应用触发自动还原 |
| 页面 / 大文件没有 body | 超过录制上限 | 查看 `truncated` / `binary` 标记，必要时改用其它方式取数 |

开发与实现约定见 [skill/astroman-capture](../skill/astroman-capture/SKILL.md)。

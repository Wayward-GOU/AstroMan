# 完整功能清单

> 以 v1.0.8 实际代码为准。安装与快速上手见 [quick-start.md](quick-start.md)。

- 项目的新建、重命名、删除
- 集合树（无限嵌套、子集合、改名、删除）
- 请求编辑：方法、URL、Params、Headers、Body、前置/后置脚本字段；Postman 风格布局——面包屑导航、方法 / URL / 环境 / 发送按钮合一的请求栏、Tab 数量角标、JSON 一键格式化、响应 Pretty/Raw 切换与一键复制；左右双栏对照（左侧请求参数、右侧响应结果，Body 编辑器与响应区自适应撑满），底部运行历史固定保留
- 请求体 JSON 增强：支持 `//` 行注释与 `/* */` 块注释（与 Postman 一致，发送前自动剥离，压测同样生效；字符串里的 `https://` 不会被误删）；`Ctrl / ⌘ + /` 一键注释 / 取消注释选定行；编辑区语法着色区分注释、字段名、字符串、数字与 `{{变量}}`，配合 21 套主题自动换色
- 接口多标签页：同一项目内可像 Postman 一样同时打开最多 20 个接口，标签按项目记忆（重启后恢复），支持点击切换、中键 / 关闭按钮关闭、一键关闭全部；编辑内容自动保存（停止输入约 1 秒后写入，切换标签、关闭标签或离开页面时立即保存），无需手动点保存即可在接口间复制参数
- 代码片段（Postman 式）：请求栏「代码」按钮打开右侧抽屉，可按 cURL / HTTP 原始报文 / JavaScript fetch / Python requests 四种格式查看并一键复制；环境变量按当前环境替换，敏感变量保持占位符，请求头缺少 Content-Type 时自动补齐
- 自动更新：启动约 5 秒后静默查询 GitHub Release 最新版本，发现新版本弹窗展示发布说明与版本号，可一键下载对应平台安装包（Windows `setup.exe` / macOS `dmg`）并启动安装；设置页可手动检查、开关启动自动检查、打开发布页
- 历史记录页：侧边栏「历史记录」集中查看最近发送记录（默认展示最新 500 条，可切换 500 / 1000 / 2000 / 5000 条），支持按接口名 / URL / 方法 / 状态码搜索，展示总数、失败数与平均耗时，点击任意记录可直接跳回原接口继续编辑；页面下方是数据大屏（近 14 天趋势、状态码 / 方法 / 耗时分布、项目与接口 Top 5、最近压测 P95 走势）
- 历史数据清理：历史记录页「清理历史」支持全部清除或按时间范围清理（最近 1 / 7 / 30 / 90 天与自定义起止时间），可勾选清理请求历史与接口运行记录，清理前实时预览将删除的条数，可选清理后压缩数据库文件回收磁盘空间；项目、集合、接口、环境变量与压测报告不受影响
- 脚本执行：发送前运行前置脚本（可读写 `request.method / url / headers / params / body`，用 `vars.set()` 生成变量并渲染进 URL、Header、Body），收到响应后运行后置脚本（`response.status / headers / body / json()`，`test(name, fn)` + `assert()` 断言，`vars` 提取变量供后续请求复用）；脚本页内置「插入示例」，覆盖时间戳、MD5 / HMAC 签名、AES 加密、RSA 加密、断言与提取 Token 等常用写法；响应区「测试」页展示断言通过率、失败原因、控制台输出与运行时变量
- 脚本加密能力：`cipher.aes / des / tripleDes`（CBC / ECB / CFB / OFB / CTR，PKCS7 / Zero / None 填充，支持 hex、base64 密钥与 IV）、`cipher.md5 / sha1 / sha256`、`cipher.hmacSha1 / hmacSha256`、`cipher.base64 / hex` 编解码，以及 `rsa.publicEncrypt`（PKCS#1 v1.5，兼容 Java 默认 RSA 加密）
- 本地发送 HTTP 请求，展示状态码、耗时、大小、响应头、响应体
- 脚本沙箱隔离：前置 / 后置 / 环境脚本在独立 Web Worker 中执行，主线程只负责终止与收结果，`while(true)` 死循环不再卡死界面；超时可配 1–30 秒（默认 5 秒），超时立即终止并把本次脚本写入的运行时变量回滚到执行前快照；Worker 不可用时自动降级为主线程执行
- 响应正文按形态分流：文本直接展示（上限 5MB，超出截断提示），二进制（图片 / PDF / 压缩包等）完整落盘到数据目录并给出本机路径，超 2MB 的文本响应同时保留截断正文与完整文件；图片与 PDF 提供内嵌预览、体积与压缩比、另存为与打开所在目录
- 耗时分解：响应区「计时」页签给出 DNS、TCP+TLS、等待首字节、正文下载四段瀑布，标注连接复用（复用连接时连接耗时为 0 且意义不同）与代理场景口径；重定向逐跳记录状态码、Location、主机与耗时，重试逐次记录原因与等待时间
- 请求控制：发送中可随时「停止」（连接、等待、下载阶段均可中断，结果为「已停止」而非报错）；重试仅针对 408 / 429 / 5xx（指数退避 200 / 400 / 800 ms，尊重 `Retry-After`，默认只重试幂等方法）；可按请求切换 HTTP/1.1 与 HTTP/2，HTTP/2 下自动剔除连接级禁用头并在 Headers 中标注
- 响应体 JSON 自动格式化，超过 5MB 自动截断
- 忽略证书校验开关、30 秒超时
- 环境变量与 `{{变量}}` 替换，优先级：运行时变量（脚本 `vars.set`）> 环境变量 > 内置变量
- 内置时间变量：`{{timestamp}}`（毫秒）、`{{timestampSec}}`、`{{isoTime}}`、`{{datetime}}`、`{{date}}`、`{{time}}`、`{{yyyyMMdd}}`、`{{yyyyMMddHHmmss}}`，同时兼容 Postman 的 `{{$timestamp}}` 写法
- 内置随机变量：`{{uuid}}`、`{{uuidNoDash}}`、`{{randomInt(1,100)}}`、`{{randomFloat(1,10,2)}}`、`{{randomString(8)}}`、`{{randomString(8, hex)}}`、`{{randomHex(16)}}`、`{{randomNumber(6)}}`、`{{randomBool}}`、`{{randomEmail}}`、`{{randomPhone}}`、`{{randomIPv4}}`
- 环境脚本：每个环境可编写一段每次请求前执行的脚本，用 `vars.set('key', value)` 生成运行时变量（如签名、traceId、nonce），请求里用 `{{key}}` 引用；脚本运行日志会并入请求编辑器的「脚本」页
- 请求历史（本地保留最近 100000 条）
- 本地压测引擎：固定并发与阶梯加压两种模式，支持并发数、压测时长、Ramp-Up 预热、思考时间、连接超时、请求超时、跟随重定向、忽略证书、目标 QPS 限速与错误率自动停止
- 压测配置入口：点击侧边栏「压测」或页面「新建压测」，弹窗内先选项目、环境，再选接口，后按 JMeter 线程组风格分组填写参数（线程组 / HTTP 请求默认值 / 流量与节奏 / 自动停止 / SLA 验收），一步完成配置并开始压测；也可从请求编辑器直接带入配置
- 流量整形：目标 QPS 令牌桶限速，可按秒精确控制发出速率
- SLA 验收阈值：P95 / P99 / 错误率 / 最小 QPS 四项可配置，报告自动逐项判定达标情况
- 压测实时指标：总请求、当前 QPS、平均 QPS（已发请求 ÷ 已运行秒数）、平均延迟、P95/P99、错误率、当前并发、当前阶段与实时状态码分布
- 压测实时曲线：吞吐量 QPS（副标显示本次采样峰值）、延迟分位（每秒采样）
- 压测报告：结束自动入库，包含成功率、P50/P75/P90/P95/P99/P99.9、标准差、TTFB 平均与 P95、APDEX、总流量，以及统一口径的 QPS 指标组（平均 / 峰值 / 最低 / 90% 分布 / 单并发 / 目标 QPS 与达成率，详见 [压测与报告](load-testing.md)）
- 报告详情：健康结论、SLA 判定、10 张核心指标卡（含 90% 分布 QPS、单并发 QPS，悬停可看口径）、完整分位表、状态码分布、错误类型分布、延迟直方图、吞吐/并发/延迟/错误率曲线、阶梯阶段汇总、每秒明细、逐请求明细与配置快照
- 请求明细：每次请求单独记录发起时间、方法、URL、请求体（模板渲染后的实际内容）、状态码、耗时、TTFB、响应大小、成功/失败与错误信息（最多保留 50000 条），报告详情页可按全部/成功/失败筛选并分页查看
- 报告导出：支持三种格式——`*.json` 归档（完整数据，含全部请求明细）、`*.html` 可视化报告（自包含样式，含 KPI、SLA 判定、趋势图、分布表与请求明细，可直接浏览器打开或打印为 PDF）、`*.xlsx` 多工作表表格（概览 / 延迟分位 / 采样明细 / 请求明细（含请求体） / 响应时间分布 / 状态码 / 错误类型 / 错误明细 / 分阶段汇总 / 配置快照）
- 压测中可随时停止，已产生的数据仍会保存成报告
- cURL 一键导入：粘贴命令自动解析方法、URL、Header、Params 与 Body，可直接选定目标集合
- 项目内接口搜索：在项目页按接口名称或 URL 跨集合检索，结果直接打开编辑
- 单接口运行历史：每次发送自动记录请求参数（Params / Headers / Body）、响应状态、响应头、响应体与耗时，在编辑器底部展开查看，每个接口保留最近 200 条并可一键清空
- 完整删除能力：项目、集合、请求（列表与编辑器内均可删）、环境与变量、压测报告均支持删除，请求历史支持全部清除与按时间范围清理，删除前统一二次确认
- 常用请求头预设：请求编辑器内置 Postman 风格分组下拉（常用/认证/内容协商/客户端信息/条件请求），选中即追加，同名自动覆盖
- 项目 JSON 导出/导入（迁移用）：项目页顶部或工作台项目卡片菜单可一键导出为 `*.astroman.json`，包含项目信息、嵌套集合、全部请求（含请求头、参数、Body、脚本、断言）与环境变量；在工作台「导入项目 → 导入项目 JSON」选择文件即可复原为新项目，项目重名时自动追加「（导入）」后缀
- 请求能力扩展：Body 支持 Form-Data（multipart 文件上传）、Binary（本地文件二进制上传）与 GraphQL（Query + Variables 自动封装）；认证页支持 Bearer / Basic / API Key（Header 或 Query）/ OAuth2（Client Credentials 一键获取令牌）；Cookie 按 RFC 6265 自动接收 Set-Cookie 并在后续请求中按域名与路径自动携带，也可在 Cookie 面板手动维护；设置页可启用 HTTP / SOCKS5 代理与客户端证书（mTLS，`*.pfx` / `*.p12`），保存后即时对全部请求生效
- 集合批量 Runner：侧边栏「批量运行」按集合顺序执行接口，支持多次迭代、请求间隔、JSON / CSV 数据驱动（每轮按行替换变量）、前置/后置脚本与断言，执行结果逐条汇总（状态、耗时、断言通过数），可一键导出 JSON 执行报告；工具栏「另存为测试套件」可把当前勾选的接口、顺序与数据文件迁成测试场景草稿
- 自动化测试 / 测试场景：套件保存到项目，用例支持 HTTP（声明式断言）、Python（pre / post / main 钩子）与压测三种类型；运行支持依赖跳过、失败策略、重试、数据集、并发与套件 setup / teardown；运行历史与报告落库，产出自包含 HTML、JSON（schemaVersion 1.0）、JUnit XML 与 summary；本地 Python 需显式授权（设置 → 网络与安全 → Python 脚本开关，同处可指定解释器路径并「探测」版本），脚本有超时、进程树回收、附件白名单与密钥脱敏；示例项目内置「示例回归（httpbin）」套件（3 个可直接运行的断言用例）
- 压测用例门禁：`kind=stress` 用例内联压测配置，运行结束按 SLA（P95 / P99 / 错误率 / 最小 QPS）逐项判定，可指定 `baselineReportId` 做基线回归；判定与失败原因进入断言、JUnit 与 HTML / JSON 报告，UI 与 CLI 使用同一套 Rust 判定
- 套件包导入导出：`*.astromantest.json` 单文件携带套件、用例、请求快照与数据集，跨机器 / CI 导入即可运行；含 Python 脚本时要求本机已授权
- CLI 与 CI：`astroman-cli test run / test list / test validate / report export / python check / suite import`，退出码 0~5；随安装包分发（Windows 便携版根目录含 `astroman-cli.exe`），仓库自带 GitHub Actions 测试流水线与 Jenkins / Actions 套件模板
- 压测计划：压测弹窗内可把当前线程组、流量、SLA 与接口保存为计划，下次直接载入复用，计划可按项目管理并随时删除
- 响应对比与另存：响应区「另存为」可把响应体保存到本地文件；「对比」以任意一条历史运行或自定义文本为基准，按行展示新增与删除差异
- OpenAPI / Swagger：项目页可把当前集合树导出为 OpenAPI 3.0 文档，也可导入 OpenAPI 3.0 / Swagger 2.0（自动按 tag 建集合、按参数生成 Params / Headers 与请求体示例）
- 集合与请求拖拽排序：集合树同一层级内拖拽调整顺序，接口列表也可拖拽排序（同级集合、同一集合内）
- 命令面板：`Ctrl / ⌘ + K` 快速搜索页面与操作（切换主题、缩放、检查更新），`Ctrl / ⌘ + 1..8` 直达对应页面
- 压测报告横向对比：报告列表勾选 2–4 份报告，对比总请求、成功率、P95/P99、QPS、APDEX 与并发等关键指标
- 离线工具箱：9 大分类 92 个工具（JSON、格式化、加密编码、文本、计算、开发辅助、网络、二维码、查询手册），全部本地计算；支持收藏、最近使用与别名搜索，含 JSONPath / JSON 对比 / Schema、JWT 验签、TOTP、文件哈希、图片 Base64、Markdown 预览、造数与证件校验、UA 与 HTTP 报文解析等，详见 [离线工具箱](toolbox.md)
- 航仔（AI 助手，自带 API Key）：支持 OpenAI 兼容 / Anthropic Claude / Google Gemini 三种协议，内置 DeepSeek、Kimi、智谱、通义千问、硅基流动、OpenRouter、Ollama、Claude、Gemini 等预设模型；既能纯聊天、答疑、出方案，也能用自然语言建项目 / 集合 / 接口、真实发送请求并解读响应、写前后置脚本、批量运行、生成并保存压测计划、查报告与导出执行记录、生成与运行测试套件（73 个业务工具 + `tool_search` 元工具，共 74 个，长尾工具按需检索）。所有新建 / 修改 / 删除 / 导入导出 / 发起压测 / 启动运行都先给出完整计划、等你确认后再弹结构化执行卡（任务 / 影响对象 / 参数 / 风险 / 预检）
- 航仔 对话体验：可随时停止生成；首个增量前遇到 429 / 5xx / 网络错误自动重试（≤2 次），已出字则只保留手动重新生成；消息支持复制、重新生成、编辑重发；顶部预算条实时显示第 N/8 轮、本轮 token 与估算费用、上下文占用与窗口大小，接近上限时变色提醒；历史过长自动异步压缩为摘要，最近几轮原文始终保留；会话支持搜索标题与正文、置顶、导出 Markdown；工具调用可按轮次查看复盘时间线并导出脱敏诊断包；模型服务支持一键拉取服务商真实模型清单（缓存 24 小时）并标注上下文窗口
- AI 用量统计（`/ai/usage`）：每次模型调用记一条，含服务商、模型、输入 / 输出 token、耗时、估算费用（美元 + 人民币）与本轮提问内容，支持按天趋势、按模型汇总、工具准确率三个视角，近 1 年可查，默认 10 条 / 页并支持右侧抽屉查看详情
- AI 入口与错误提示：浮在界面上的宇航员形象「航仔」打开航仔（`/ai` 页面内自动隐藏）——设计稿同款形象（透明底贴图 `src/assets/buddy.png`）：大弧面深蓝面罩里两只青色准线发光眼、白色装甲配青绿光条、胸口「AI」徽标；待机上下浮动，可以按住拖到窗口任意位置、松手停在原地，位置随下次启动恢复；单击即进航仔，拖拽时有轻微甩动惯性、悬停放大（`prefers-reduced-motion` 下关闭动画），设置页「AI 辅助（航仔）」卡片可直接进入航仔 与用量统计；服务商返回的 401 / 402 / 403 / 404 / 429 / 5xx、模型下线、上下文超长等报错统一转成中文并给出处理建议
- 系统监视（Windows / macOS）：CPU 每核心占用与频率、内存/交换区、磁盘容量与读写速率、网络接口上下行速率与累计流量、电池状态、运行时长与系统信息；GPU 利用率在 Windows 下通过 PDH 采集，其他平台自动隐藏
- 本机 IP 展示：Windows 走 Win32 `GetAdaptersAddresses`，macOS / Linux 走 `getifaddrs` + 系统路由表，采集全部网卡的 IPv4/IPv6 地址、MAC 与默认网关，主 IP 卡片支持一键复制，网卡列表与系统信息同步展示
- 系统监视采样：3/5/10 秒可调，切换间隔自动重置曲线，支持暂停与手动刷新，保留近 90 个采样点并以本地 SVG 曲线展示 CPU/内存/GPU、网络吞吐与磁盘 I/O 趋势
- 进程监视（任务管理器风格）：列出全部进程的名称、PID、CPU 占用率、内存占用与占比、可执行文件路径，支持按 CPU / 内存排序、按名称 / PID / 路径搜索、只看高占用（CPU ≥ 50% 或内存 ≥ 10%）；确认后可直接结束进程，系统关键进程（System、csrss、lsass 等）与 AstroMan 自身会被拒绝，权限不足时给出明确提示

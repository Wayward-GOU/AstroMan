# 本地压测与报告

AstroMan 内置轻量压测引擎，面向「日常容量摸底 + 回归验证」，不要求理解 JMeter 的线程组与配置元件。

## 新建压测

侧边栏「压测」→「新建压测」，按分组填写：

1. **选择目标**：项目、环境、接口；也可从请求编辑器直接带入配置
2. **线程组**：并发数、持续时间
3. **流量与节奏**：固定并发 / 阶梯加压、Ramp-Up 预热、思考时间、目标 RPS、连接 / 请求超时、跟随重定向、忽略证书
4. **自动停止**：错误率或响应时间达到阈值时停止
5. **SLA 验收**：P95、P99、错误率、最小 RPS

配置可保存为「压测计划」，下次直接载入；计划按项目管理并可删除。

## 实时指标与曲线

- 总请求、RPS、平均延迟、P95 / P99、错误率、当前并发、当前阶段、状态码分布
- QPS、延迟分位、错误率实时曲线

## 报告

结束后自动入库，包含：

- 成功率、P50 / P75 / P90 / P95 / P99 / P99.9、标准差、TTFB 平均与 P95、APDEX、总流量、最大 / 平均 QPS
- 健康结论、SLA 逐项判定、状态码分布、错误类型、延迟直方图、阶梯阶段汇总、每秒采样
- 逐请求明细（发起时间、方法、URL、请求体、状态码、耗时、TTFB、响应大小、错误信息，最多 5 万条）

导出格式：

| 格式 | 用途 |
|---|---|
| JSON | 完整归档，含全部请求明细 |
| HTML | 自包含可视化报告，可直接浏览器打开或打印 PDF |
| Excel | 概览 / 延迟分位 / 采样 / 请求明细 / 分布 / 状态码 / 错误 / 阶段 / 配置多工作表 |

## 报告对比

报告列表勾选 2–4 份，对比总请求、成功率、P95 / P99、QPS、APDEX 与并发等关键指标。

## 边界

- 当前是**本机单进程压测**，未提供分布式压测节点；并发上限取决于本机 CPU、内存、网络与目标服务
- 压测会真实打到目标服务，请先确认环境和配额
- 压测类操作在航仔里不会自动执行，必须由你确认

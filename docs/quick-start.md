# 快速开始

> 安装包下载见 [README](../README.md#下载安装)，系统兼容性见 [compatibility.md](compatibility.md)。

首次启动后自带「示例项目」，可以直接拿它练习；想从零开始就按下面六步走。

**1. 建项目、建集合**

工作台点「新建项目」，进入项目后右键集合树可新建子集合。项目与集合只影响组织方式，不会影响请求本身。

**2. 配环境变量**

侧边栏「环境」里建一个环境，把 `base_url`、`token` 等可变内容写进去，勾选为当前环境。请求里用 `{{base_url}}`、`{{token}}` 引用，切换环境即可整体换域名和凭证。

内置变量可直接使用：`{{timestamp}}`、`{{uuid}}`、`{{randomInt(1,100)}}`、`{{randomString(8)}}`。

**3. 调一个接口**

新建请求，填方法、URL、Params、Headers、Body，点「发送」。响应区可切换 Pretty / Raw，并查看状态码、耗时、大小与响应头；请求栏「代码」按钮能生成 cURL / 原始报文 / fetch / Python 四种代码片段。

变量优先级：运行时变量（脚本 `vars.set`）> 环境变量 > 内置变量。

**4. 用脚本生成签名或密文**

请求编辑器「脚本」页分前置（发送前）与后置（收到响应后）。右上角「插入示例」会直接把可运行的代码填进编辑器，改几个变量名即可用。详见 [脚本 API 与加密示例](script-api.md)。

**5. 压测与报告**

侧边栏「压测」新建压测，选项目 / 环境 / 接口后配置并发、时长与 SLA 阈值，开始后实时看 RPS、P95/P99 与状态码分布；结束后报告自动入库，可导出 JSON / HTML / Excel。

**6. 让航仔 代劳**

点右侧屏幕中间的机器人进入航仔，先在顶部「模型服务」里配置一家服务商（DeepSeek / Kimi / 智谱 / 通义千问 / Claude / Gemini / Ollama 等，兼容 OpenAI 协议的服务都能接）。航仔 是双模式的：既能纯聊天、答疑、给方案，也能动手操作软件。例如：

```text
解释一下 HTTP/2 多路复用和 HTTP/1.1 的核心区别
给我一份下单接口的压测方案，包括并发、时长和 SLA 阈值
列出本机所有项目，并按请求数量排序
给「创建订单」接口写一个 HMAC-SHA256 签名前置脚本
```

只想聊方案时不会去翻你的项目数据；只有你明确指向本机某个接口或说「帮我查 / 帮我改 / 帮我跑」时才会动工具。

凡是会新建、修改、删除、导入导出或发起压测的操作，航仔 都会先用文字把完整计划列出来（压测计划会写明模式、并发、时长、阶段和 SLA），你确认后才弹执行框，确认后才真正落库或开跑；取消则不做任何改动。

每次调用的 token 与预估费用可在航仔 顶部「用量统计」查看。

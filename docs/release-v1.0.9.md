# AstroMan v1.0.9 发布说明

> 发布日期：2026-11-03 · 基线：v1.0.8 · 相对 v1.0.8 改动 51 个文件、约 9.7 千行

## 一句话概括

v1.0.9 新增**抓包分析**（M9）：本机 MITM 代理解密 HTTP / HTTPS，按域名分组查看、导出 HAR / ZIP、改参重发，手机同 Wi-Fi 也能抓；同时把航仔从 74 个工具扩到 **92 个**，并修正了发送 / 批量执行绕过脚本与断言的问题。

---

## 一、新增模块：抓包分析

| 能力 | 说明 |
|---|---|
| 抓包内核 | 基于 hudsucker 0.25 的本机 MITM 代理，支持 HTTP/1.1 与 HTTP/2；HTTPS 按 SNI 动态签发证书 |
| 录制 | 默认监听 `127.0.0.1:8888`，端口被占用自动向后顺延；监听地址可切 `0.0.0.0` 供手机访问 |
| 根证书 | 本地生成并保存到 `<数据目录>/certs/`；Windows 用 `certutil -addstore -user Root` 装进当前用户受信任根，无需管理员；支持重新生成、导出 PEM、查看 SHA-1 / SHA-256 指纹与有效期 |
| 证书状态 | 安装状态 5 秒刷新；注册表检测之外补 `certutil` 兜底，避免「已安装却显示未信任」 |
| 系统代理 | 只改 Windows 当前用户 WinINET 代理，接管前备份、停止时还原；应用启动时清理上次异常退出留下的代理备份，避免断网 |
| 流量存储 | 全部在内存，上限 5000 条 / 128 MB body；单条 body 保留 2 MB 前缀，超过 8 MB 不缓冲；重启应用即清空 |
| 列表与分组 | 左侧按域名分组，支持关键字过滤（域名 / 路径 / 方法 / 状态）、只看错误、展开 / 折叠、自动滚动；配置与运行状态显示在顶部 |
| 流量详情 | 概览、请求（头 + Body）、响应（头 + Body）、原始报文四个页签；文本可格式化 / 复制 / 另存，图片直接预览 |
| HAR 导出 | 全部流量或单个域名分组导出标准 HAR 1.2，可导入 DevTools / Charles |
| ZIP 导出 | 全部或单个分组导出，解压即读：`index.html` 汇总页、`README.txt`、`summary.json`、`capture.har`，以及每条流量的 `meta.json` / `request.txt` / `response.txt`（图片与二进制另外落原始文件） |
| 改参重发 | 可改方法、URL、请求头与 Body；自动剔除 `host` / `content-length` / `connection` 等客户端重算头；不跟随重定向，超时 120 秒 |
| 录制状态 | 录制中重发会经本机代理并新增一条流量；未录制时直接发送，响应只在弹窗展示，不写入列表 |
| 手机抓包 | 监听切 `0.0.0.0` 后显示可复制的「电脑 IP:端口」；支持导出根证书到手机，iOS 需再打开「证书信任设置」的完全信任 |
| 边界说明 | 证书固定（pinning）与 HTTP/3（QUIC）无法解密；微信可能绕过 Wi-Fi 代理，自己的小程序建议走微信开发者工具；不做 VPN / TUN 全局劫持 |

配套文档：[抓包](capture.md)；工作台首页新增抓包入口、四步上手、手机检查清单与边界提示。

## 二、航仔 AI Agent：74 → 92 个工具

| 变化 | 说明 |
|---|---|
| 抓包域 +7 | `capture_status`、`capture_flow_list`、`capture_flow_get`、`capture_start`、`capture_stop`、`capture_repeat`、`capture_export` |
| 测试域 +10 | 数据集 `test_dataset_list / get / save / delete`、套件包 `test_suite_import / export`、`test_run_list`、产物 `test_artifact_list / export`、`test_preflight` |
| 批量创建 | 新增 `request_batch_create`，同一集合一次确认最多新建 50 个请求，避免模型循环调用 `request_create` |
| 发送链路 | `send_request` 支持传 `requestId`，完整执行环境脚本 → 前置脚本 → HTTP → 后置脚本与断言；只传 `method + url` 时按裸请求发送 |
| 批量链路 | `run_batch` 每个请求都走环境 / 前置 / 后置脚本与断言，成功判定改为「2xx/3xx + 断言全过 + 无脚本错误」 |
| 写操作确认 | 新增 10 项抓包 / 测试 / 批量创建确认文案，抓包启动、停止、重发、导出与测试数据集、套件包、产物导出全部走确认卡 |
| 计划预览 | 新增抓包预览（端口、监听地址、解密域名、忽略规则、上游代理），并在重发前读取原始方法与 URL |
| 提示词与目录 | 系统提示词补齐抓包、测试数据集 / 套件包 / 运行列表 / 产物 / 预检规则；工具目录保持核心 27 个，其余按关键词检索 |

工具总数 92 = 79 业务 + 12 工具箱 + `tool_search`；其中测试域 22 个、抓包域 7 个；写操作工具 48 个、危险工具 30 个。

## 四、修复的问题

| 现象 | 根因 / 修复 |
|---|---|
| 航仔给已保存的接口发请求时，环境脚本、前置 / 后置脚本和断言都没有执行 | `send_request` 只按 method + url 发裸请求；改为传 `requestId` 时复用界面发送链路，完整执行脚本与断言并回传断言结果 |
| 批量运行时脚本和断言不生效，失败统计只看状态码 | `run_batch` 改为逐个请求执行完整链路，成功 = 2xx/3xx + 断言全过 + 无脚本错误 |
| 抓包重发必须先处于录制状态，且不能改参数 | 重发改为「任意流量可改方法 / URL / 头 / Body」；录制中走代理并新增记录，未录制时直连、只弹结果 |
| 域名分组右键菜单在窗口底部被裁掉 | 菜单边界按实际高度（约 190px）重新计算，贴边时向内收 |
| 重发弹窗内容过高时无法操作底部按钮 | 弹窗 Body 限制 66vh 并允许滚动 |
| 域名分组只能导出 HAR，无法单独导出 ZIP | 分组右键同时提供「导出该分组 HAR」与「导出该分组 ZIP」 |
| 停止抓包后系统代理残留导致电脑断网 | 停止录制时无条件按备份还原；应用启动时清理异常退出留下的代理状态 |
| 根证书已安装但界面仍显示未信任 | 证书状态检测增加 `certutil` 兜底，并按 5 秒轮询刷新 |
| 航仔测试运行列表把当前页条数当成总数 | `test_run_list` 只报本页条数与页码，不再伪造 `total` |

## 五、升级与兼容

- **数据库**：本次不新增表、不改表结构，抓包流量只存内存，升级不需要迁移；v1.0.8 的项目、历史、报告、测试套件与密钥可直接使用
- **系统要求**：Windows 10 1809+ / Windows 11；macOS 10.15+。抓包的一键证书安装与系统代理接管目前只支持 Windows，macOS / Linux 需手动导入 PEM、手动设置代理
- **构建**：新增 `hudsucker` / `zip` / `http-body-util` / `bytes` 依赖；hudsucker 0.25 要求 Rust ≥ 1.86
- **安全**：根证书私钥保存在本机 `<数据目录>/certs/`，不要分发；抓包只用于你自有或已获授权的流量；证书固定与 HTTP/3 无法解密属于协议限制
- **降级**：如需回退，直接安装 v1.0.8 覆盖即可，数据目录无需改动

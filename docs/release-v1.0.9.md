# AstroMan v1.0.9 发布说明

> 发布日期：2026-11-04 · 基线：v1.0.8 · 相对 v1.0.8 改动 94 个文件、约 2.6 万行

## 一句话概括

v1.0.9 新增**抓包分析**（M9）与**记事本 / 待办**（M10）：抓包补齐断点改包、Map Local / Map Remote 与弱网模拟；记事本支持四种类型、自然语言快速记录、应用内提醒、稍后提醒、截图生成待办与图片附件。同时把航仔从 74 个工具扩到 **92 个**，新增 HAR 导入与请求级认证加密，并修掉了发送链路、多标签与提醒相关的若干问题。

---

## 一、新增模块：抓包分析

| 能力 | 说明 |
|---|---|
| 抓包内核 | 基于 hudsucker 0.25 的本机 MITM 代理，支持 HTTP/1.1 与 HTTP/2；HTTPS 按 SNI 动态签发证书 |
| 录制 | 默认监听 `127.0.0.1:8888`，端口被占用自动向后顺延；监听地址可切 `0.0.0.0` 供手机访问 |
| 根证书 | 本地生成并保存到 `<数据目录>/certs/`；Windows 用 `certutil -addstore -user Root` 装进当前用户受信任根，无需管理员；支持重新生成、导出 PEM、查看 SHA-1 / SHA-256 指纹与有效期 |
| 证书状态 | 安装状态 5 秒刷新；注册表检测之外补 `certutil` 兜底，避免「已安装却显示未信任」 |
| 系统代理 | 只改 Windows 当前用户 WinINET 代理，接管前备份、停止时还原；应用启动时清理上次异常退出留下的代理备份，避免断网 |
| 流量存储 | 全部在内存，上限 5000 条 / 128 MB body；单条 body 保留 2 MB 前缀，超过 8 MB 不缓冲；重启应用即清空 |
| 列表与分组 | 左侧按域名分组，支持关键字过滤（域名 / 路径 / 方法 / 状态）、只看错误、展开 / 折叠、自动滚动；配置与运行状态显示在顶部 |
| 流量详情 | 概览、请求（头 + Body）、响应（头 + Body）、原始报文四个页签；文本可格式化 / 复制 / 另存，图片直接预览 |
| HAR 导出 | 全部流量或单个域名分组导出标准 HAR 1.2，可导入 DevTools / Charles |
| ZIP 导出 | 全部或单个分组导出，解压即读：`index.html` 汇总页、`README.txt`、`summary.json`、`capture.har`，以及每条流量的 `meta.json` / `request.txt` / `response.txt`（图片与二进制另外落原始文件） |
| 改参重发 | 可改方法、URL、请求头与 Body；自动剔除 `host` / `content-length` / `connection` 等客户端重算头；不跟随重定向，超时 120 秒 |
| 录制状态 | 录制中重发会经本机代理并新增一条流量；未录制时直接发送，响应只在弹窗展示，不写入列表 |
| 手机抓包 | 监听切 `0.0.0.0` 后显示可复制的「电脑 IP:端口」；支持导出根证书到手机，iOS 需再打开「证书信任设置」的完全信任 |
| 边界说明 | 证书固定（pinning）与 HTTP/3（QUIC）无法解密；微信可能绕过 Wi-Fi 代理，自己的小程序建议走微信开发者工具；不做 VPN / TUN 全局劫持 |

### 抓包进阶：断点改包 / 映射 / 弱网

| 能力 | 说明 |
|---|---|
| 断点 | 请求发出前或响应下发前暂停，可改方法 / URL / 请求头 / 请求体，或改状态码 / 响应头 / 响应体；支持放行、改包放行、中止（返回 403） |
| 断点队列 | 最多同时挂起 32 条，120 秒未处理自动放行；停止录制或「全部放行」会清空队列；流式与二进制响应只能改头与状态码 |
| 本地映射 | 命中后不访问上游，直接返回内联 JSON / HTML 或本地文件（≤ 50 MB，每次命中实时读取），可改状态码、Content-Type 与响应头 |
| 远程映射 | 命中后把请求转发到另一套 host / 协议 / 端口，便于联调环境切换与灰度域名替换 |
| 弱网模拟 | 预设 4G / 3G / 弱 Wi-Fi / 极差，也可自填延迟、抖动、带宽与丢包率；丢包直接返回 504，用于验证重试与降级逻辑 |
| 规则持久化 | 四类规则统一保存在 `<数据目录>/capture/intercept.json`，重启后仍在；顶部「拦截」抽屉统一编辑，匹配 URL 支持 `*` 通配与包含匹配 |

配套文档：[抓包](capture.md)；工作台首页新增抓包入口、四步上手、手机检查清单与边界提示。

## 二、新增模块：记事本与待办

| 能力 | 说明 |
|---|---|
| 记录类型 | `todo` 待办 / `note` 笔记 / `idea` 灵感 / `reference` 资料四种，类型只影响分组、图标与筛选，都可设截止与提醒 |
| 视图与分组 | 今天 / 本周 / 全部 / 已完成；按逾期 → 今天 → 之后 → 无截止分组，置顶 → 优先级 → 截止时间 → 更新时间排序 |
| 快速记录 | 列表顶部常驻「记一笔」，自然语言解析「明天10点 / 每周五 / #工作 / !」，回车即存并保持焦点；多行文本首行作标题、其余作正文 |
| 标签 | 多标签、左栏新建与筛选、整块着色（同一标签在列表 / 卡片 / 编辑器颜色一致），支持搜索标题与正文 |
| 详情与编辑 | 点击条目打开右侧抽屉，默认占窗口 50%（窄窗口最小 520px）；新建从同一抽屉进入，打开即聚焦标题 |
| 提醒 | 到期应用内卡片提醒，支持提前量、每天 / 工作日 / 每周 / 每月重复、稍后 10 分钟、暂停 1 小时 / 到今天结束、免打扰时段；多条提醒聚合，完成或删除后可撤销 |
| 稍后提醒语义 | 稍后时间就是真实触发时间，到点重新弹出；展示时间与「已稍后」状态随提醒送达同步刷新 |
| 截图生成待办 | 粘贴 / 拖入 / 选择截图，调用已勾选「支持图片识别」的 AI 服务商识别待办清单，预览确认后批量创建；原图作为附件保存在本机 |
| 图片附件 | 编辑器内 `Ctrl+V` 或拖拽图片直接挂到当前条目，按内容哈希去重、多条记录可共享；支持查看、另存与移除 |
| 入口 | 侧边栏「记事本」（角标 = 逾期 + 今天）、工作台「今日待办」卡片、托盘「快速记录 / 暂停提醒 / 打开记事本」、全局快捷键 `Ctrl+Alt+N` 唤起迷你窗口 |
| 数据安全 | 数据只存本机 SQLite，随备份归档；只有主动点「识别」时图片才发送给已配置的模型服务商 |

配套设计：[记事本与待办技术设计](notes-design.md)。

## 三、航仔 AI Agent：74 → 92 个工具

| 变化 | 说明 |
|---|---|
| 抓包域 +7 | `capture_status`、`capture_flow_list`、`capture_flow_get`、`capture_start`、`capture_stop`、`capture_repeat`、`capture_export` |
| 测试域 +10 | 数据集 `test_dataset_list / get / save / delete`、套件包 `test_suite_import / export`、`test_run_list`、产物 `test_artifact_list / export`、`test_preflight` |
| 批量创建 | 新增 `request_batch_create`，同一集合一次确认最多新建 50 个请求，避免模型循环调用 `request_create` |
| 发送链路 | `send_request` 支持传 `requestId`，完整执行环境脚本 → 前置脚本 → HTTP → 后置脚本与断言；只传 `method + url` 时按裸请求发送 |
| 批量链路 | `run_batch` 每个请求都走环境 / 前置 / 后置脚本与断言，成功判定改为「2xx/3xx + 断言全过 + 无脚本错误」 |
| 写操作确认 | 新增 10 项抓包 / 测试 / 批量创建确认文案，抓包启动、停止、重发、导出与测试数据集、套件包、产物导出全部走确认卡 |
| 计划预览 | 新增抓包预览（端口、监听地址、解密域名、忽略规则、上游代理），并在重发前读取原始方法与 URL |
| 图片识别 | 服务商新增「支持图片识别」标记，截图生成待办只列出已勾选且可用的视觉模型；识别走独立调用，不影响聊天协议与用量统计 |
| 提示词与目录 | 系统提示词补齐抓包、测试数据集 / 套件包 / 运行列表 / 产物 / 预检规则；工具目录保持核心 27 个，其余按关键词检索 |

工具总数 92 = 79 业务 + 12 工具箱 + `tool_search`；其中测试域 22 个、抓包域 7 个；写操作工具 48 个、危险工具 30 个。

## 四、导入与安全

| 变化 | 说明 |
|---|---|
| HAR 导入 | 项目页可导入浏览器 DevTools / Charles / Fiddler 的 HAR 1.2：按 host 建集合，查询串拆到 Params，表单与 multipart 还原为 Form；`Authorization` / `Cookie` 保留值但默认不启用，base64 上传体宁可不导入也不写坏 |
| 请求级认证加密 | 请求认证里的 `token` / `password` / `value` / `client_secret` 等敏感字段用主密钥 AES-256-GCM 加密入库；未解锁时读取只清空敏感字段，不回吐密文；换钥 / 重置密钥同步重写或清空 |
| 旧数据迁移 | 启动时自动把历史请求里的认证明文加密，迁移幂等；未安装密钥库时拒绝写入明文 |

## 六、修复的问题

| 现象 | 根因 / 修复 |
|---|---|
| 航仔给已保存的接口发请求时，环境脚本、前置 / 后置脚本和断言都没有执行 | `send_request` 只按 method + url 发裸请求；改为传 `requestId` 时复用界面发送链路，完整执行脚本与断言并回传断言结果 |
| 批量运行时脚本和断言不生效，失败统计只看状态码 | `run_batch` 改为逐个请求执行完整链路，成功 = 2xx/3xx + 断言全过 + 无脚本错误 |
| 抓包重发必须先处于录制状态，且不能改参数 | 重发改为「任意流量可改方法 / URL / 头 / Body」；录制中走代理并新增记录，未录制时直连、只弹结果 |
| 域名分组右键菜单在窗口底部被裁掉 | 菜单边界按实际高度（约 190px）重新计算，贴边时向内收 |
| 重发弹窗内容过高时无法操作底部按钮 | 弹窗 Body 限制 66vh 并允许滚动 |
| 域名分组只能导出 HAR，无法单独导出 ZIP | 分组右键同时提供「导出该分组 HAR」与「导出该分组 ZIP」 |
| 停止抓包后系统代理残留导致电脑断网 | 停止录制时无条件按备份还原；应用启动时清理异常退出留下的代理状态 |
| 根证书已安装但界面仍显示未信任 | 证书状态检测增加 `certutil` 兜底，并按 5 秒轮询刷新 |
| 航仔测试运行列表把当前页条数当成总数 | `test_run_list` 只报本页条数与页码，不再伪造 `total` |
| 接口详情切换到其他标签后仍显示上一个接口的执行结果 | 路由复用同一个编辑器实例但没清瞬态；切换时统一清空响应 / 脚本 / 计时 / 差异弹窗，并给在途请求加归属判断，旧结果不再落到新标签 |
| 快速连点多个接口标签时，慢保存会把路由推回上一个标签 | 切换与加载各加令牌，只认最后一次点击；被关闭标签 / 返回带走的排队切换直接作废 |
| 长响应切换接口或 Pretty / Raw 后停在上一份的滚动位置 | 新响应渲染与视图切换后正文滚回顶部 |
| 标签多到横向滚动时，当前标签可能不在视野内 | 打开 / 切换标签时自动把激活标签滚进视野 |
| 接口改名后「打开其他接口」下拉仍显示旧名称 | 自动保存时同步更新的标签元数据与下拉快照 |

## 七、升级与兼容

- **数据库**：结构版本 4 → 6，升级自动执行迁移：补齐 `requests.net_json`、`notes.done_at / deleted_at / deleted_from_status`、`note_files` / `note_file_links`、`ai_providers.supports_vision`，并把老 `note` 且有截止时间的记录归一化为 `todo`；迁移前保留 `pre-migrate` 快照
- **认证加密**：升级后首次启动会把历史请求认证中的明文敏感字段加密；如果主密钥未解锁，保存请求会明确报错而不是落明文
- **抓包**：流量只存内存，重启清空；断点 / 映射 / 弱网规则独立保存在 `capture/intercept.json`，升级不影响
- **系统要求**：Windows 10 1809+ / Windows 11；macOS 10.15+。抓包的一键证书安装与系统代理接管目前只支持 Windows，macOS / Linux 需手动导入 PEM、手动设置代理
- **构建**：新增 `hudsucker` / `zip` / `http-body-util` / `bytes` / `tauri-plugin-global-shortcut` 等依赖；hudsucker 0.25 要求 Rust ≥ 1.86
- **安全**：根证书私钥保存在本机 `<数据目录>/certs/`，不要分发；抓包只用于你自有或已获授权的流量；证书固定与 HTTP/3 无法解密属于协议限制
- **降级**：如需回退，直接安装 v1.0.8 覆盖即可，数据目录无需改动；若已升级数据库，回退前请用设置页恢复 `pre-migrate` 快照

# AstroMan v1.1.2 发布说明

> 发布日期：2026-11-22　｜　数据库：v20　｜　集群协议：v2（增量兼容）
>
> 完整变更见 [CHANGELOG](../CHANGELOG.md#112--2026-11-22)，能力清单见 [features.md](features.md)。

## 版本亮点

v1.1.2 的主线是 **分布式压测二期** 与 **参数池 / Token 池**：

- 多台电脑压测不再需要手抄 IP：局域网自动发现、审批配对、按本机能力分配并发。
- 从节点读不到环境变量的问题收口：主节点加密下发、变量体检、`master_wins / local_wins` 可选。
- 多账号 / 多 Token 场景可用：建池先定列、Excel 模板导入、全部列同名注入或指定列映射。
- 集群下池由主节点按全局 VU 切片下发，Token 刷新由主节点单飞，不需要在从节点重复配置。
- 航仔可以直接读集群 / 池的真实状态，并在下发前提示旧节点兼容与切片体量风险。

## 新增与升级

### 分布式压测（二期）

- UDP 17802 多播 + 各网卡广播发现，Beacon 每 2 秒、TTL 6 秒、不含令牌；保留 6 位配对码与手动 IP。
- 审批配对：待接受列表、接受 / 拒绝 / 自动接受，每 IP 5 秒限流、待接受上限 3。
- 5 轮时钟探测对齐；偏移误差超过 200ms 的采样丢弃并计入 `droppedSamples`。
- 并发分配：`auto` 按预算、`even` 平均、`custom` 权重 + 每节点 min/max；上限不足或下限冲突直接拒绝。
- 采集健康度：首样超时、采样缺口、失联状态可见；失联标记 `lost`，报告标注「结果不完整（N/M 节点）」。
- 端口生命周期：17801 → 17811..17860 → 系统临时端口自动避让，任务终态自动释放监听。
- 环境变量：EnvBundle（X25519 + HKDF-SHA256 + AES-256-GCM）加密下发；`{{os:NAME}}` 白名单；`required_vars` 缺失在 prepare 阶段阻断。
- 变量体检：按普通 / 密钥 / 系统 / 数据池展示主节点与各从节点状态，不返回明文。
- 池切片：全局 VU 对齐、单节点 ≤ 64 MB、下发前体量估算；Token 刷新主节点单飞。
- 兼容提示：节点表显示「兼容 / 变量下发 / 池切片」；计划含 `column` 绑定时拒绝旧从节点并列出节点名。
- 报告：集群总览、峰值专题、节点贡献与 QPS 曲线；节点序列落库 `cluster_report_samples`。

### 参数池 / Token 池

- 自定义列（DB v20）：`data_pools.columns_json` 与 `data_pool_items.data_json`，列名规则、最多 24 列、首列必填。
- Excel：一键下载模板（首行列名、整列文本、含说明 Sheet），按表头导入，返回 inserted / skipped / ignoredColumns / numericWarnings。
- 列管理：重命名按列迁移、增删、排序；旧池按 `value,account` 兼容。
- 绑定：`column="*"` 全部列同名注入、具体列映射、旧式首列；同池多绑定共用条目、mode 必须一致。
- 执行：`per_vu` / `per_request` / `random`；401 / 403 换下一条；Token 到期前 30 秒预刷新、失败退避、连续失败 3 次失效。
- 安全：敏感池在列表、预览与 AI 工具结果中逐列脱敏，明文需二次确认且 30 秒自动隐藏。
- 示例项目：内置「07 数据池示例」、两个示例池与两个压测计划（per_vu 映射 / per_request 轮换）。

### 航仔与体验

- 航仔新增 `cluster_*`（17 个）与 `pool_*`（7 个）工具，写操作先确认。
- 集群摘要新增「池兼容 / 变量下发 / 池切片 / 数据池体量」。
- 请求编辑器「格式化 JSON」支持 `{{变量}}`，数值占位可不加引号。
- 修复输入法回车误发送、旧报告 Body 指标显示 0、GET 请求体被丢弃、跨域重定向携带认证头、GBK 响应乱码等问题。

## 升级与兼容

- 数据库自动从 v16 升级到 v20，只做加法，不重建表；旧池与旧报告可直接读取。
- 主从协议仍为 v2：旧从节点可参与不使用自定义列的计划；使用 `column` 绑定时需升级从节点。
- 旧从节点如果没有加密公钥，只能读取本机同名环境，集群页会标注「旧版」。
- 未绑定数据池的计划保持原快路径，不增加额外开销。

## 已知限制

- 集群仅支持同一局域网、内网明文 WebSocket；跨网段、断线重连与失联后并发重分配尚未支持。
- 池内容为 prepare 时快照，开跑后改池 / 改列 / 刷新不影响本次运行。
- 单节点池切片上限 64 MB，超大池需精简条目、减少列或增加从节点。
- Excel 模板下载与文件导入只在数据池页由用户操作，航仔不读取本地 xlsx。

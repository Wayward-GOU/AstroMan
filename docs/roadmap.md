# 路线图

> 只列可验证的状态：已交付写「已完成」，未写代码的一律标「规划中」。

## 已交付

| 阶段 | 内容 | 状态 |
|---|---|---|
| M1 | 工程骨架、请求调试、环境变量、历史 | 已完成 |
| M2 | 本地压测引擎、实时曲线、压测报告 | 已完成 |
| M3 | 自带 Key 的 AI 助手「航仔」：三协议、61 业务工具 + `tool_search`、双模式、写操作确认、流式渲染、用量与费用 | 已完成 |
| M4 | cURL 一键导入、项目 JSON 导出 / 导入 | 已完成 |
| M5 | Postman / Apifox 集合导入、安装包验证 | 已完成 |
| M6 | AI Agent 深度增强：停止 / 重试 / 工具硬超时、上下文预算与摘要、注入隔离、动态模型、预算条、确认卡、消息操作、复盘时间线、会话管理 | 已完成 |
| M7 | 品牌升级为 AstroMan、数据迁移、双安装包（标准 / 离线）、32 位与便携版 | 已完成 |

## 规划中（尚未实现）

| 方向 | 说明 |
|---|---|
| 链路编排 Flow | 可视化多接口串行、条件分支、上下游参数传递 |
| 定时巡检 | Cron 调度、健康检查、Webhook 告警（飞书 / 钉钉 / 企业微信） |
| CLI / CI | 无头运行集合与压测，输出 JUnit 报告 |
| WebSocket 调试 | 当前仅支持 HTTP / HTTPS 与 GraphQL 请求体，WebSocket 未实现 |
| 分布式压测 | 多压测节点调度与结果汇总 |
| 团队协作 / 同步 | 可选私有服务端，当前纯本地 |
| Linux 桌面端 | 构建与验证尚未提供 |
| 全局 / 集合级变量 | 当前为环境变量 + 脚本运行时变量两级 |
| Postman / HAR 导出 | 当前支持 Postman 导入、OpenAPI 导入导出、项目 JSON 导出 |

> 产品品牌文档中的目标用户、Slogan 与长期愿景属于方向描述，不代表上述规划功能已经可用。
